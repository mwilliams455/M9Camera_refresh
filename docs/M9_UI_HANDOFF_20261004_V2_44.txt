FINAL UI DECISIONS
- Photo then Motion: plain text strip below the shutter, muted inactive label, bright selected label and thin underline; both retain 48 dp touch targets.
- Top left: torch and Night toggles. The redundant M9 Colour heading was removed; render selection remains at the lower right.
- Top centre: shooting-controls chevron, geometrically centred independently of AE-L visibility. It points up while its popup is open.
- Top right: AE-L, with compact timer/capture-mode status in the remaining space.
- Manual row: ISO / Shutter / EV / Focus / WB / settings gear. The gear opens the app's real settings directly. WB uses the existing straight ruler and long-press reset.
- Shooting popup: two rows of three labelled icons for self-timer, grid, histogram, highlights, shadows and lens lock. Tap to toggle; hold the first five for choices. Current values and selected states are visible and exposed to accessibility.
- Last enabled values are remembered in m9_overlay_ui / quick_last_0..4. First explicit enable defaults: 2-second timer, 3x3 grid, RGB histogram, 100% highlight threshold and 0% shadow threshold. Existing preferences are not reset. 0% shadows is enabled; -1 means off.
- Lens lock uses the original action and is unavailable without auto lens switching or more than one lens choice.
- Other capture modes remains below the tiles; Unlimited remains accessible. VIDEO/RAWVIDEO options and video preference screens are hidden, not deleted.
- Popup closes through the cross, back, outside tap, camera stop or capture/processing/final-save lock. Any options dialog closes with it. Actions recheck availability.
- Night is the existing Photon capture mode, not an additive modifier on Motion. Turning Night off restores the remembered Photo/Motion choice; direct Photo/Motion selection exits Night.
- Render picker contains M9 / Monochrom / M10-R / M11. Only M9 is enabled. Never present uninstalled profiles as functional.
