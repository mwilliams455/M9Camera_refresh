NEW BEHAVIOR
Settings > Image > Monochrom profiles (while Mono is selected).
Save up to 20 named profiles, each containing contrast, sharpness, toning hue and toning strength. Apply, update from current settings, rename or delete a profile. Manual changes display the active name as modified and do not overwrite the saved profile.
Reset current look restores Standard contrast, Standard sharpness, Sepia remembered and toning Off. Saved profiles remain. Reset, overwrite and delete are confirmed in the app.
When toning is Off, its hue remains remembered and the hue control is disabled. Saved profile summaries show both the Off state and remembered hue.

ISOLATION AND PERSISTENCE
M9 and Monochrom have separate profile collections and active markers; the same profile name can exist in both. Mono profiles do not include EV, Auto ISO, shutter, timer, brackets, output, diagnostics or M9 controls. They affect the existing preview/JPEG image preferences, not the linear Monochrom DNG.
The existing shutter snapshot keeps queued photographs tied to their selected look. Profile metadata is app-wide rather than per lens. Stale per-lens imports cannot overwrite the collection, active marker or four image values. Profiles use default preferences and therefore participate in the existing settings backup/restore mechanism.
